4. Layout Lock Rules (บังคับทุกหน้า)

⚠️ ถ้าไม่ทำ: content ล้นออกนอกจอ, numpad หาย, layout แตกบน iOS

โครงสร้าง Flex Column ที่ถูกต้อง

HEADER
flexShrink:0 — ไม่ยืด ไม่หด
CARD / STRIP
flexShrink:0 — ไม่ยืด ไม่หด
CONTENT AREA ← ยืดเต็มพื้นที่ที่เหลือ
flex:1, minHeight:0
TOAST
flexShrink:0
BOTTOM BAR
flexShrink:0
NAV / FOOTER
flexShrink:0
  • ✅ใช้ height:"100vh", height:"100dvh" ทั้งคู่เสมอ (fallback + iOS Safari)
  • ✅content area ที่ scroll ได้ → flex:1, minHeight:0, overflow:hidden
  • ✅content area ที่ไม่ scroll (numpad) → flex:1, minHeight:0, justifyContent:"center"
  • ❌ห้าม hard-coded height เป็น px เช่น height:680
  • ❌ห้ามลืม minHeight:0 บน flex:1 — Safari จะ overflow
  • ❌ห้ามลืม flexShrink:0 บน bottom bar

10. Cross-browser Rules

  • ✅ทุก button → WebkitAppearance:"none", appearance:"none", WebkitTapHighlightColor:"transparent"
  • ✅minHeight: 48px (action buttons), 54px (primary CTA), 56px (nav)
  • ✅scroll area → WebkitOverflowScrolling:"touch" + overscrollBehaviorY:"contain"
  • ✅canvas → position:"absolute" (ห้าม fixed — iOS webview crash)
  • ✅canvas → ใช้ devicePixelRatio + ctx.setTransform + ctx.scale(dpr,dpr)
  • ✅ทุก @keyframes ต้องมี @-webkit-keyframes คู่กัน
  • ✅font size ทุกตัว ≥ 12px (ป้องกัน iOS auto-zoom)
  • ✅ไม่ใช้ gap: ใน inline style — ใช้ marginRight/Left แทน (Safari iOS 14)
  • ❌ห้าม position:"fixed" — ใช้ position:"absolute" แทน

11. Toast Logic (Safari-safe)

ต้องใช้ JS-driven width + pb.offsetWidth force reflow เสมอ — CSS animation บน Safari ใช้ไม่ได้กับ position:absolute element 
const showToast = useCallback((msg)=>{
  clearTimeout(toastTimer.current); clearTimeout(cntTimer.current);
  setToastMsg(msg); setToast(true);

  setTimeout(()=>{
    const pb = pbarRef.current; if(!pb) return;
    pb.style.WebkitTransition = "none"; pb.style.transition = "none";
    pb.style.width = "100%";
    pb.offsetWidth; // ← force reflow (Safari จำเป็นต้องมี)
    pb.style.WebkitTransition = "width 4s linear";
    pb.style.transition       = "width 4s linear";
    pb.style.width = "0%";
  },30);

  let rem = 4; setToastSec(rem);
  const tick=()=>{rem--;if(rem>0){setToastSec(rem);cntTimer.current=setTimeout(tick,1000);}};
  cntTimer.current = setTimeout(tick,1000);
  toastTimer.current = setTimeout(()=>setToast(false),4000);
},[]);

const resizeCanvas = useCallback(()=>{
  const cvs=cvsRef.current; if(!cvs) return;
  const dpr=window.devicePixelRatio||1;
  const w=cvs.parentNode.offsetWidth, h=cvs.parentNode.offsetHeight;
  cvs.width=Math.floor(w*dpr); cvs.height=Math.floor(h*dpr);
  cvs.style.width=w+"px"; cvs.style.height=h+"px";
  cvs.getContext("2d").setTransform(1,0,0,1,0,0);
  cvs.getContext("2d").scale(dpr,dpr);
},[]);

17. Deploy Checklist

ตรวจทุก checkbox ก่อน deploy ทุกหน้า

HTML / Meta

  • font size ทุกตัว ≥ 12px
  • minHeight: 48px (buttons), 54px (primary CTA), 56px (nav)
  • viewport: maximum-scale=1, user-scalable=no
  • PWA meta: apple-mobile-web-app-capable
  • theme-color: #FFD700

Layout

  • phone shell: flexDirection:column + overflow:hidden
  • ทุก fixed section มี flexShrink:0
  • content area มี flex:1 + minHeight:0
  • scroll area: height:100% + overflowY:auto
  • ไม่มี hard-coded height px
  • body background: #E8D96A ทุกหน้า
  • มี @media 768px + 1024px breakpoints

Cross-browser

  • WebkitAppearance:none ทุก button
  • WebkitTapHighlightColor:transparent ทุก interactive
  • WebkitOverflowScrolling:touch บน scroll area
  • @-webkit-keyframes คู่กับ @keyframes ทุกตัว
  • pbar ใช้ JS-driven width + pb.offsetWidth
  • canvas: position:absolute (ไม่ใช่ fixed)
  • canvas: devicePixelRatio + setTransform
  • ไม่มี gap: ใน inline style

Icons / Assets

  • ไม่มี emoji ใน JSX (ใช้ Tabler Icons)
  • อัปโหลด cjx_logo.png พร้อมกับ index.html
  • nav href ตรงกับชื่อไฟล์จริง
  • SESSION_USER guard uncomment (production)

PWA Icons

  • apple-touch-icon.png อยู่ที่ root (ไม่ใช่ใน icons/)
  • icon ทุกไฟล์เป็น RGB (ไม่มี alpha) — ไม่มีขอบดำบน iOS
  • manifest.json มี icons ครบ (192, 512, 180, 167, 152)
  • manifest start_url ถูก: Netlify "/" / GitHub Pages "/repo-name/"
  • ไม่มี icon-1024.png ใน repo (ใช้เฉพาะ App Store)
